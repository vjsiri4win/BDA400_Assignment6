## Assignment 6 – Technical Analysis using R, Visualization Phase

Vijay Sirivella



**Brief Description**



This project implements an interactive portfolio dashboard using R Shiny. Historical stock data is fetched from Yahoo Finance and can be filtered by stock symbol, date range, and time frame. The dashboard provides line, area, and candlestick-style charts and dynamically overlays Moving Averages, RSI, and MACD.

A Moving Average crossover trading rule generates Buy, Sell, or Hold signals. Buy and Sell signals are annotated on the price chart.
