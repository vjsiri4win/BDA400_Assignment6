# BDA400 Assignment 6

Open `R/app.R` in RStudio

The app includes:

* Yahoo Finance data collection
* Daily/Weekly/Monthly filtering
* Line/Area/Candlestick-style charts
* Moving Average overlay with customizable periods
* RSI with customizable period
* MACD with customizable fast/slow/signal periods
* Independent indicator toggles
* Moving-average crossover Buy/Sell/Hold signals
* Chart annotations
* Latest-signal summary
* Recent-data table
* Basic error validation

The app requires internet access to retrieve Yahoo Finance data.
